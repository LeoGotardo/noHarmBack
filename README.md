# noHarmBack — moved

**This repository is archived.** The NoHarm server now lives in
[`backend/` of LeoGotardo/noHarm](https://github.com/LeoGotardo/noHarm/tree/master/backend),
in one repository with the app.

- **History:** every commit from here is there too, rewritten under
  `backend/`, so `git log` and `git blame` work across the move. The tags
  `v1.0.0`…`v1.0.2` are there as `backend-v1.0.0`…`backend-v1.0.2`.
- **Releases:** from v1.0.3 on, a release is one `vX.Y.Z` tag in noHarm. Up to
  v1.0.2, this repository's `vX.Y.Z` is the server half of each release; rolling
  back to one of them is described in noHarm's `backend/docs/operations.md`.
- **Issues and pull requests:** open them on
  [noHarm](https://github.com/LeoGotardo/noHarm).
- **Licence:** Apache 2.0, unchanged — [`LICENSE`](LICENSE) here and in
  `backend/` there.

The documentation this repository shipped is still in [`docs/`](docs/), as it
was at the move.
